1)Encapsulation
 ->Building data and methods into single unit 
 Why Encapsulation
   ->protect object data from unauthorized access
   ->improve code security and realiability
   ->Makes code easier to maintain
   
 Types and methods
   ->Public members()- the name attribute can be access directly
   ->Protected members() - indicated by (_)single undrscore 
   ->private members() - Indiacted by double underscore 
   
  getter and setter 
   ->Instead of accessing private data directly, provide methods to read or modify it
